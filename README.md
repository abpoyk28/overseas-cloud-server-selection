## 带宽计费：三种口径混着比，结论一定是错的

海外云服务器的带宽计费至少有三种完全不同的口径，单位不同、产品线不同，直接比单价会得出相反结论。

**口径一：美元/GB，按流量阶梯计价。** 阿里云国际站的香港和新加坡，10Mbps 档 0.087 美元/GB，100Mbps 档 0.262，500Mbps 档 1.025；东京 0.091 / 0.275 / 0.767；硅谷 10Mbps 档最便宜，0.082，但 100Mbps 档跳到 0.392，500Mbps 档 1.095。

**口径二：元/Mbps/小时，按固定带宽计费。** 腾讯云香港 ≤5Mbps 部分 0.08 元，超过 5Mbps 部分 0.25 元；新加坡 0.0625 / 0.25；东京和硅谷 0.063 / 0.25。同一家还有一套按流量的价格：香港 1.00 元/GB、新加坡 0.80、东京 0.80、硅谷 0.50 元/GB。

**口径三：套餐超额流量，美元/GB。** 腾讯云国际版轻量的套餐内流量用完后，东京 0.13 美元/GB，香港、首尔、雅加达、圣保罗 0.12，新加坡 0.081，硅谷、法兰克福、柔佛 0.077。

这三个数字放在一起，最容易被误读的是腾讯云。0.50 元/GB 是 CVM 按流量计费的价格，0.077 美元/GB 是轻量套餐的超额流量单价，两条产品线，不能合并成一个“腾讯云硅谷流量价”。

比价之前先把三件事对齐：币种、计费单位（每 GB 还是每 Mbps 每小时）、是不是同一条产品线。三个都对上了，数字才有意义。

选固定带宽还是按流量，有个业界参考线：带宽利用率高于 10% 时优先考虑固定带宽。换算成场景就是，API 服务、企业官网这种流量平稳的业务，固定带宽成本可预测；有促销活动的电商、视频分发这类波动大的业务，按流量更灵活，但要设成本上限。

“不限流量”这四个字也要看清在哪个机房生效。腾讯云国际版轻量的锐驰型是 200Mbps 峰值带宽加不限流量，香港和柔佛都不提供。同样是 2核4G，香港只能买带宽加月流量包的组合，15.00 美元/月，配 30Mbps 和 2048GB；新加坡可以买锐驰型，8.50 美元/月，配 200Mbps 和不限流量。差别在产品类型，不全是地域溢价。

## 六个采购坑，和下单前的七项核验

**坑一：只看带宽数字，不看线路类型。** 同样标 30Mbps，走普通国际线路和走回国优化线路，回国延迟能差三倍。带宽数字和线路等级要一起看。

**坑二：把峰值带宽当保障带宽。** 轻量型产品标注的峰值带宽是上限值，不是资源隔离的保障值。腾讯云官方文档自己写明了这一点：从中国大陆访问境外轻量实例，受运营商跨境线路影响可能出现明显延迟和丢包，套餐里的公网带宽只保证是“峰值带宽”。高并发业务要用独享带宽，并把这一条写进合同。

**坑三：忽略流量包的月度限制和超额单价。** “固定带宽 + 月流量包”是轻量产品的标准结构，超出部分单独计费，而且单价按机房差得不少：硅谷 0.077、新加坡 0.081、香港 0.12、东京 0.13 美元/GB。做视频或下载类业务，先拿月流量包额度除以 30 天，看日均够不够。

**坑四：元/GB 和美元/GB 混着比。** 阿里云国际站用美元，腾讯云和不少国内厂商用人民币。比价时统一到同一种币种和同一个计费单位，别拿美元单价直接和人民币单价相减。

**坑五：忘算晚高峰的丢包成本。** 普通国际线路晚高峰丢包率 1%–5%，实时业务碰上这个数字很难受。测试必须覆盖 20:00–23:00。

**坑六：忽略特殊机型的不退费规则。** 部分主打 IP 纯净度的机型开通后不退费，当月删除也不退。下单前把退费条款翻一遍。

下单前按这七项走一遍：

1. 明确目标用户分布，大陆为主、东南亚、东北亚还是北美
2. 明确业务能容忍的延迟，50ms 以内是硬指标、50–100ms 可接受、100ms 以上无所谓
3. 明确需要的线路类型，普通国际、BGP 多线、CN2 GIA 还是回国优化线路
4. 明确带宽模式，固定带宽、按流量、峰值带宽还是独享带宽
5. 算清月流量包额度够不够，超额单价多少
6. 向厂商要测试 IP，在本地网络跑 ping 和 traceroute
7. 测试时段覆盖工作日上午、晚高峰 20:00–23:00、周末各一轮

自测的具体动作：先 `ping 服务器IP` 看平均延迟和丢包率，再用 `traceroute` 或 `mtr` 看路由。从大陆到香港的优质线路，骨干网跳数不应超过 15 跳，超过 20 跳基本是绕路了，晚高峰一定会卡。Windows 下可以用 WinMTR 替代。

还有一条容易被忽略：地域和可用区在实例创建后无法更改。买错机房只能重新买一台，不能改配置搬过去。下单前把用户位置想清楚。
